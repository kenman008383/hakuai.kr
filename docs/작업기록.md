## 2026-11-12 — 하쿠 마크, 입문 01~09편, 연락처, 첫 화면 영상 목록

"영상 파악" 채팅창의 대화를 읽고 정리했어요.

**정해진 작업 방식**
- 하쿠는 **유튜브 주소 + 복습 자료 PDF**를 보낸다. Claude가 강의 페이지와 슬라이드를 만들어 바로 공개한다.
- 유튜브 로봇 확인 때문에 자막을 못 읽는 일이 많다. 그럴 때는 PDF만 보고 만들고, 우회하지 않는다. PDF에 질문 문장이 없어 Claude가 바꿔 쓴 것은 하쿠에게 알린다.
- 공개하면 하쿠에게 **유튜브 설명란 맨 윗줄**과 **고정 댓글 문장**을 함께 드린다.
  - 설명란: `📘 강의 자료(PPT·PDF)와 따라 할 질문: https://hakuai.kr/chatgpt/intro/<번호>/`
  - 고정 댓글: `이번 강의에서 쓴 질문 문장과 슬라이드는 여기서 받을 수 있어요 👉 https://hakuai.kr/chatgpt/intro/<번호>/` (00편은 "질문 문장" 대신 "정리 내용")
- 새 편을 올리면 앞 편 끝의 '다음 강의' 안내를 잇고, 앞 편 슬라이드도 다시 만든다.
- 슬라이드 글자가 넘치면 디자인은 그대로 두고 JSON 문장만 줄인다.

**대화와 한 일**
- 하쿠: PPT 디자인은 한 챕터 안에서는 별도 명령이 없는 한 항상 같게 → 규칙으로 정함
- 하쿠: 사이트가 PC·스마트폰에서 열리는 것 확인, HTTPS 강제 설정 완료
- 하쿠: 주소창·즐겨찾기·홈 화면 아이콘 → 픽셀 캐릭터 등 여러 시안 끝에 **"하쿠" 도장 마크(K1)**로 결정. 파비콘·홈 화면 아이콘·로고·링크 미리보기에 넣고, 홈 화면 아이콘은 브라우저 방식으로 열리게 함
- 입문 01~09편 공개 (영상 주소 + 복습 자료 PDF)
  - 01 첫 질문, 이렇게 보내세요 — https://youtu.be/254EBvM-HDg
  - 02 답이 길다면? 다시 부탁하세요 — https://www.youtube.com/watch?v=zUteU4Zd_XE
  - 03 AI 답변, 그대로 믿어도 될까? — https://youtu.be/85TLPEOo_Ys
  - 04 개인정보, 보내기 전 확인! — https://youtu.be/Ph9kKZhbtHs
  - 05 모임 공지, 함께 만들어봐요 — https://youtu.be/W7pAnG4grus
  - 06 같은 내용, 말투만 바꿔봐요 — https://youtu.be/1YHE140x1Y0 (자막을 읽어 영상 길이·구간 목차까지 넣음)
  - 07 뒤죽박죽 메모 정리하기 — https://youtu.be/XHT6OAGmZ6A
  - 08 빠뜨리지 않게! 체크리스트 만들기 — https://youtu.be/Bg1FeixPNf8 (두 번째 질문은 PDF 내용을 보고 Claude가 질문 형태로 바꿈)
  - 09 하루 계획에 여유 넣기 — https://www.youtube.com/watch?v=rGHgk_GzfkY (설명란의 '영상 순서'로 구간 목차, 길이 7:30)
- 하쿠: 영상에 홈페이지 주소를 붙이는 방법 → 설명란 맨 위, 고정 댓글, 채널 링크(유튜브 스튜디오 → 맞춤설정 → 기본 정보 → 링크), 영상 속 글자. 00~09편 설명란 줄과 고정 댓글 문장을 정리해 드림
- 하쿠: 운영자 연락처가 없는데 괜찮은지 → 지금은 꼭 필요하지 않지만 넣는 것을 추천. 하쿠가 이메일을 정해 줘서 모든 페이지 맨 아래와 소개 페이지에 '운영: 하쿠'와 문의 이메일을 넣음 (소개 문장은 Claude가 씀)
- 하쿠: 첫 화면에서 영상이 바로 보이게 → 첫 화면에 "강의 영상, 순서대로 보세요" 칸을 만들어 00~09편 썸네일 목록을 넣음 (썸네일은 유튜브로, 제목은 강의 페이지로). 끝에 '다음 편: 입문 10 사진 속 글자 읽어보기' 예고
