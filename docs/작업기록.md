## 2026-11-26 — 검색 노출 늘리기 (제목·설명, 구조화 데이터, RSS)

**대화 내용**
- 하쿠: 사람들이 더 많이 볼 수 있게 노출하는 방법 → 사이트 안 개선, 유튜브→사이트 연결, 네이버 블로그·카페, 공유, 꾸준한 확인으로 안내

**확인한 것**
- 강의 페이지 제목에는 이미 "ChatGPT"가 들어 있음, 슬라이드에도 hakuai.kr 주소가 이미 있음, 유튜브 설명 맨 위에 강의 자료 주소도 이미 넣고 있음 → 그대로 둠

**한 일**
- 페이지 제목·설명에 사람들이 쓰는 검색어(챗GPT·무료 강의·강의 슬라이드) 반영
  - 홈: "하쿠의 AI 첫걸음 — 초보자를 위한 ChatGPT(챗GPT) 무료 강의"
  - 단계 목록: "ChatGPT(챗GPT) 초급 강의 — 목표 · 공개 N편"
  - 강의: "강의 제목 — ChatGPT(챗GPT) 중급 05 | 하쿠의 AI 첫걸음" (강의 제목이 앞에 오게). 강의 주소는 그대로

- `/rss.xml` 새로 만듦 (최근 강의 50편). 모든 페이지 head에 RSS 링크
- `/chatgpt/`는 입문 목록과 내용이 같아서 대표 주소를 `/chatgpt/intro/`로 알리고 사이트맵에서 뺌
- 강의가 아직 없는 단계(고급)와 사이트 검색·404 페이지는 검색 결과에 넣지 않게(noindex). 고급 강의가 올라오면 자동으로 풀림
- 배포 후 확인: 강의 페이지 VideoObject·BreadcrumbList, `/rss.xml` 50편 정상
- 구글 Search Console: 홈·입문·초급·중급 목록이 이미 색인돼 있음을 확인, 바뀐 제목 반영을 위해 4개 모두 색인 생성 다시 요청

**만든 파일**
