# Q&A 답변하기

질문은 Google 설문지 → 하쿠의 Google 시트에 쌓인다(시트 이름: "하쿠의 AI 첫걸음 Q&A 접수", 설문지 주소는 `src/data/site.js`의 `qnaFormUrl`).
공개 사이트에는 **하쿠가 승인(merge)한 답변만** 올라간다. Claude는 main에 직접 올리지 않는다.

## 1. 새 질문 모으기
- Google Drive 커넥터로 시트를 읽는다. 이미 `src/content/qna/`에 있는 질문(타임스탬프로 구분)은 건너뛴다.
- 스팸·광고·욕설·의미 없는 글은 버리고, 버린 개수만 보고에 적는다.

## 2. 개인정보 지우기
- 이름, 전화번호, 이메일, 주소, 계좌, 주민번호 같은 정보는 질문 문장에서 지우거나 "(개인정보 삭제)"로 바꾼다.
- 닉네임은 본인이 적은 경우에만 쓰고, 실명처럼 보이면 뺀다.

## 3. 답변 쓰기
- 하쿠 영상 말투: 짧고 쉬운 존댓말, 3~6문장, 따라 할 수 있는 순서로.
- 관련 강의가 있으면 "입문 00 강의의 '…' 부분을 참고해 보세요"처럼 연결한다.
- 모르는 것, 영상·강의에 없는 사실(요금, 최신 기능)은 단정하지 않고 "공식 안내를 확인해 주세요"라고 쓴다.
- 답하지 않는 질문: 계정 해킹·결제 문제·의료·법률·투자 상담 → 답 대신 공식 고객센터나 전문가 안내.

## 4. 파일 만들기
`src/content/qna/<YYYY-MM-DD>-<3자리 번호>.json`
```json
{
  "id": "2026-11-13-001",
  "track": "chatgpt",
  "level": "intro",
  "ep": "입문 01",
  "date": "2026-11-13",
  "status": "done",
  "q": "질문 (개인정보 삭제 후)",
  "a": "답변",
  "nick": "닉네임(선택)",
  "receivedAt": "시트의 타임스탬프"
}
```
- 관련 강의를 모르면 `"ep": "일반"`, `level`은 가장 가까운 단계.

## 5. 승인 요청
- `npm run build` 통과 확인 후 `qna/<날짜>` 브랜치에 커밋하고 Pull Request를 연다. 제목: `Q&A 답변 <날짜> (<개수>건)`.
- PR 본문에 질문·답변을 표로 정리하고, 버린 질문 수와 판단이 애매했던 질문을 적는다.
- 하쿠가 휴대폰 GitHub 앱에서 읽고 Merge하면 자동으로 공개된다. 고칠 점을 댓글로 남기면 고쳐서 다시 올린다.
